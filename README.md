# 🃏 小丑牌 (Balatro)

Balatro 风格的扑克 + 小丑牌组合游戏 —— 核心循环版。

## 玩法

- 从 52 张标准扑克中抽 8 张手牌，选出 1-5 张组成牌型出牌
- 9 种牌型（同花顺 → 高牌），配合 6 张 Joker 卡加成
- 3 关盲注（300 / 500 / 800 分），通关进商店买 Joker，变强再战
- 内置 AI 出牌助手（本地启发式枚举，无需联网）

## 运行

直接用浏览器打开 `index.html` 即可，无需安装、无需后端。

```
open index.html
```

## 快捷键

| 键 | 功能 |
|----|------|
| Enter | 出牌 |
| D | 弃牌 |
| Esc | 关闭弹窗/商店 |
